# 2_PRACTICE – 16 exam-style programs

[⬅ main index](../README.md)

General exam-style programs built from the blocks, useful when a new task mixes topics. Copy one, then change the names, ranges and messages.
They are numbered **in learning order** - basics → algorithms → text → files → classes - so working through them from 01 to 16 is also a revision plan.
