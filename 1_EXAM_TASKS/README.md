# 1_EXAM_TASKS – the 20 official INF.04 console tasks

[⬅ main index](../README.md)

Every console task from every official sheet (SG + SD/AG variants), solved exactly as the sheet and its grading key say. **One folder = one task**: the sheet(s) (`exam_sheet_…pdf`), the grading key(s) (`grading_key_…`), `main.cpp` and a **README** with the task, the key checklist, the documentation-comment pattern of that year, and how to run it.

Folder names are `<category>_<topic>__<YYYY-MM>_task<N>`, so tasks on the same topic sit together (all `class_` tasks one after another) and `2023-06_task2` = INF.04-**02**-**23.06**-SG.
